# Gerenciador de Tarefas

App web simples para organizar tarefas, feito com HTML, CSS e JavaScript puro.

## Recursos
- Adicionar, concluir, editar (duplo clique) e remover tarefas
- Prioridade baixa, média e alta
- Filtros: todas, pendentes e concluídas
- Barra de progresso
- Tema claro e escuro
- Tarefas salvas no navegador (`localStorage`)

## Como rodar
Abra o `index.html` no navegador.
